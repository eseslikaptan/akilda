# Akılda · site

Akılda iOS uygulamasının herkese açık sayfaları (GitHub Pages: https://eseslikaptan.github.io/akilda/):

- `gizlilik.html`: gizlilik politikası (App Store Connect'te gizlilik URL'si)
- `destek.html`: destek sayfası (App Store Connect'te destek URL'si); uygulamadaki "Bu kartta hata var" buradan bildirim açar
- `index.html`: tanıtım; uygulamadan paylaşılan meydan okuma bağlantılarını (`#/meydan?…`) uygulamada açar (`akilda://`)

Uygulamanın kaynak kodu ayrı ve gizli bir depodadır.
